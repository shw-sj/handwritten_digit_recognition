  一、image_loader.py — 数据获取接口

>>> from image_loader import load_torchvision_data, get_dataset, preprocess_single


1.1 load_torchvision_data(dataset_name, ...) —— ★推荐：torchvision 自动加载★

    首次调用时 torchvision 自动下载数据集到 ./data/ 目录，后续直接使用缓存。
    无需网络代理配置，无需手动下载。

    # ---------- 正式训练：全量数据 ----------
    digits  = load_torchvision_data('mnist')
    letters = load_torchvision_data('letters')

    # ---------- 调试 / 演示：少量数据快速验证 ----------
    digits  = load_torchvision_data('mnist', max_train=500, max_test=200, verbose=False)

    参数:
        dataset_name: 'mnist'（数字0-9） 或 'letters'（字母A-Z）
        split_val:    是否划分验证集，默认 True
        train_ratio:  训练集比例，默认 0.6
        val_ratio:    验证集比例，默认 0.2
        random_seed:  随机种子，默认 42
        verbose:      打印进度，默认 True
        max_train:    最多加载训练样本数，None=全量。调试/演示时设 500~2000，正式训练不传此参数
        max_test:     最多加载测试样本数，None=全量。调试/演示时设 200~500，正式训练不传此参数

    !! 注意：正式训练时不要传 max_train/max_test，否则数据量不足会导致模型效果很差。

    返回格式:
        {
            'X_train': (N_tr, 28, 28) uint8,   'y_train': (N_tr,) int32,
            'X_val':   (N_va, 28, 28) uint8,   'y_val':   (N_va,) int32,
            'X_test':  (N_te, 28, 28) uint8,   'y_test':  (N_te,) int32,
            'classes': ['0','1',...,'9']  或  ['A','B',...,'Z']
        }

    数据量:
        mnist:    训练60000张 + 测试10000张 → 划分后 训练36000 / 验证12000 / 测试10000
        letters:  训练124800张 + 测试20800张 → 划分后 训练74880 / 验证24960 / 测试20800

    图像已经过完整预处理流水线：灰度化 → 高斯去噪 → OTSU二值化 → 28×28归一化


1.2 get_dataset(config) —— 统一数据获取（支持 torchvision + 本地文件）

    方式一：torchvision 模式（★推荐）

        # 正式训练
        config = {
            'use_torchvision': True,
            'torchvision_datasets': ['mnist', 'letters'],  # 可只加载一个
        }
        datasets = get_dataset(config)

        # 调试/演示（传递额外参数给底层 load_torchvision_data）
        config = {
            'use_torchvision': True,
            'torchvision_datasets': ['mnist'],
            'torchvision_kwargs': {'max_train': 500, 'max_test': 200},
        }
        datasets = get_dataset(config)
        # datasets['digits']  → 数字数据集
        # datasets['letters'] → 字母数据集

    方式二：本地文件模式（加载自定义手写数据 + MNIST IDX）

        config = {
            'digits_dir':   'data/digits/',         # 手写数字目录（可选）
            'letters_dir':  'data/letters/',        # 手写字母目录（可选）
            'mnist_dir':    'data/mnist/',           # MNIST IDX目录（可选）
            'target_size':  28,
            'train_ratio':  0.6,
            'val_ratio':    0.2,
            'random_seed':  42,
        }
        datasets = get_dataset(config)

    返回格式与 load_torchvision_data() 一致。


1.3 preprocess_single(img, target_size=28) —— 单张图像预处理（GUI画板实时识别用）

    输入: PIL.Image 或 numpy (H,W)/(H,W,3)
    返回: (preprocessed, binary) 均为 (28,28) uint8


1.4 load_prepared_data(dataset_name) —— 备选：加载 prepare_data.py 生成的 .npz

    digits  = load_prepared_data('mnist')
    letters = load_prepared_data('letters')

    需先运行 python prepare_data.py，否则会报 FileNotFoundError。

  二、image_feature.py — 特征提取接口
================================================================================

>>> from image_feature import extract_features, get_feature_dim, get_all_methods

2.1 extract_features(images, method='pixel', **kwargs) —— ★核心接口★

    参数:
        images: (N, 28, 28) uint8 — 即 image_loader 返回的图像数组
        method: 'pixel' | 'projection' | 'structure'

    返回:
        features: (N, D) float32 特征矩阵

    三种方法详情:

    ┌──────────────┬──────────────┬──────────────────────────────────────┐
    │ method       │ 维度 D       │ 说明                                  │
    ├──────────────┼──────────────┼──────────────────────────────────────┤
    │ 'pixel'      │ 784 (28×28)  │ 像素网格展平为向量                    │
    │              │ 或196(14×14) │ 通过 grid_size=14 切换                │
    │ 'projection' │ 56 (28+28)   │ 水平投影直方图(28) + 垂直投影(28)     │
    │ 'structure'  │ 17           │ Hu矩(7)+笔画穿越(8)+孔洞数(1)+宽高比(1)│
    └──────────────┴──────────────┴──────────────────────────────────────┘

    使用示例:

        F_pixel = extract_features(X, method='pixel', grid_size=28)  # (N, 784)
        F_proj  = extract_features(X, method='projection')           # (N, 56)
        F_struc = extract_features(X, method='structure')            # (N, 17)

2.2 get_feature_dim(method, image_size=28, **kwargs) —— 获取输入维度

    用于配置BP网络输入层大小:

        input_dim = get_feature_dim('pixel', grid_size=28)       # → 784
        input_dim = get_feature_dim('projection', image_size=28)  # → 56
        input_dim = get_feature_dim('structure')                  # → 17

2.3 get_all_methods() → ['pixel', 'projection', 'structure']

  三、data_augmentation.py — 数据增强接口

>>> from data_augmentation import augment_dataset, augment_single

3.1 augment_dataset(images, labels, factor=3, random_seed=42) —— ★批量增强★

    参数:
        images: (N, H, W) uint8
        labels: (N,) int
        factor: 扩充倍数（默认3，即最终数据量 = N * 3）

    返回:
        aug_images: (N*factor, H, W) uint8
        aug_labels: (N*factor,) int

    增强策略（每张图每种变换独立随机应用）:
      - 旋转 ±10°           (概率 0.7)
      - 平移 ±3px           (概率 0.7)
      - 缩放 ±10%           (概率 0.5)
      - 弹性形变            (概率 0.4)

3.2 augment_single(img, rng=None) —— 单张随机增强（GUI测试用）
