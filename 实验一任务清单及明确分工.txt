================================================================================
                    实验一：基于BP算法的手写数字识别
                    —— 任务清单及明确分工（3人小组）
================================================================================

【实验基本要求】
  - 编程语言不限（建议Python，生态丰富）
  - 图形界面不做硬性要求（但我们将其作为创新加分项）
  - 提交：源代码 + 实验报告（~2000字）

================================================================================

【创新得分策略 —— 我们做的加分项】
  1. 识别对象扩展（三大识别模式）：
     ★ 手写数字识别（0-9，10类）———— 基础任务
     ★ 手写英文字母识别（A-Z，26类）———— 创新扩展1
     ★ 语音数字识别（0-9语音）———— 创新扩展2
  2. 特征提取：实现3种以上图像特征提取方法（像素法+投影特征+结构/轮廓特征）并做对比
  3. 语音特征：实现MFCC（梅尔频率倒谱系数）音频特征提取
  4. 算法优化：BP算法加入动量项、自适应学习率、L2正则化、Dropout等改进
  5. 图形界面：三大模式切换（手写画板·数字/字母 + 语音录制） + 实时识别 + 结果显示
  6. 模型对比：引入CNN卷积神经网络与BP网络进行性能对比
  7. 数据增强：图像旋转、平移、缩放扩充；音频加噪、变速扩充
  8. 可视化：混淆矩阵、训练曲线、特征分布图、MFCC频谱图等

================================================================================

【任务清单与分工 —— 公平分配，每人核心工作量相当】

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
成员A：图像数据准备与图像特征提取模块
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
任务描述：

  1. 手写数字数据采集（0-9，10类）
     - 小组成员每人手写0-9数字各10-20个样本
     - 编写图像预处理脚本：灰度化、二值化(OTSU)、高斯去噪、尺寸归一化
     - 收集MNIST数据集作为补充对比数据

  2. 手写英文字母数据采集（A-Z，26类）★创新★
     - 小组成员每人手写A-Z大写字母各5-10个样本
     - 也可结合EMNIST-letters公开数据集
     - 统一预处理流水线（与数字处理保持一致）

  3. 图像特征提取实现（至少3种方法）
     a) 像素特征法（14×14或28×28黑白像素网格展开为向量）
     b) 投影特征（水平投影直方图 + 垂直投影直方图）
     c) 轮廓/结构特征（Hu矩、笔画穿越次数、孔洞数、宽高比等）

  4. 特征对比分析
     - 输出不同特征提取方法下的特征向量维度
     - 为后续不同特征的识别效果对比做好准备

  5. 图像数据增强（创新加分）
     - 对训练样本进行随机旋转(±10°)、平移(±3px)、缩放(±10%)、弹性形变
     - 使训练数据扩充3-5倍

  6. 编写 image_feature.py 和 image_loader.py 模块，提供统一接口供成员B调用

  7. 数据集划分
     - 数字：训练集(60%)、验证集(20%)、测试集(20%)
     - 字母：训练集(60%)、验证集(20%)、测试集(20%)

  预计工作量占比：33%

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
成员B：BP神经网络核心 + 语音数字识别模块
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
任务描述：

  1. BP神经网络类实现（从零编写，不调用现有NN框架）
     - 输入层维度：根据特征向量自动适配
       · 数字图像特征：N维（由成员A确定）
       · 字母图像特征：N维（同上）
       · 语音MFCC特征：M维（通常13-40维MFCC系数）
     - 隐含层：1-2层，神经元数可配置（如128-64）
     - 输出层：
       · 数字识别：10个神经元（0-9）
       · 字母识别：26个神经元（A-Z）
       · 语音数字：10个神经元（0-9）
     - 激活函数：Sigmoid / ReLU / Tanh（支持多种切换）
     - 输出层：Softmax
     - 损失函数：交叉熵损失（Cross-Entropy Loss）

  2. 训练优化模块
     - 小批量梯度下降（Mini-batch SGD）
     - 动量项（Momentum）加速收敛
     - 自适应学习率衰减策略
     - L2正则化防止过拟合
     - Early Stopping（基于验证集loss）
     - 模型参数保存与加载（.npy或.pkl格式）

  3. 语音数字识别 —— 完整流水线 ★创新★
     a) 语音数据采集：
        - 小组成员每人朗读0-9数字各10-20遍
        - 或使用公开数据集（如Google Speech Commands、Free Spoken Digit Dataset）
     b) 音频预处理：
        - 降采样至16kHz、归一化
        - VAD（语音活动检测）去除静音段
        - 分帧、加窗（汉明窗）
     c) MFCC特征提取：
        - 提取13-40维MFCC系数（含一阶差分、二阶差分）
        - 帧级别特征聚合为固定长度向量（取平均+标准差）
     d) BP网络训练：
        - 使用MFCC特征训练BP网络进行语音数字分类
        - 与图像识别共用同一个BP网络类（仅维度不同）
     e) 音频数据增强：
        - 添加高斯白噪声
        - 时间拉伸/压缩
        - 音调微调（pitch shifting）

  4. 评价指标模块（统一用于数字/字母/语音）
     - 每个类别的Precision、Recall、F1-score
     - 整体准确率、混淆矩阵
     - Macro-Average 和 Micro-Average
     - 生成混淆矩阵热力图

  5. 超参数调优实验
     - 对比不同隐含层数、神经元数的效果
     - 对比不同学习率、激活函数的效果
     - 对比不同特征提取方法下的识别率

  6. 编写 bp_network.py / train.py / audio_processor.py 模块

  预计工作量占比：33%

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
成员C：图形界面 + CNN对比 + 系统集成 + 实验报告
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
任务描述：

  1. 图形界面开发（PyQt5 / Tkinter / Streamlit 任选）
     界面包含三大模式（Tab切换或侧栏切换）：

     【模式一：手写数字识别】
       - 手写画板（鼠标/触摸绘制，可调节笔刷粗细）
       - "识别"按钮：调用BP模型输出识别结果
       - 结果显示区：识别数字 + 置信度柱状图（各数字概率）
       - "清空"按钮重置画板

     【模式二：手写英文字母识别】★创新★
       - 同上画板，识别目标为A-Z
       - 显示识别字母 + 26类概率柱状图

     【模式三：语音数字识别】★创新★
       - "录音"按钮（按住录音/松开停止，或点击录制定时长）
       - 实时显示录音波形
       - "识别"按钮：调用语音BP模型输出识别结果
       - 显示识别数字 + 置信度
       - 显示MFCC频谱图（可选）

     【通用功能】
       - 批量测试：选择图片/音频文件夹，批量识别并统计准确率
       - 模型切换下拉框：BP(像素特征) / BP(投影特征) / BP(结构特征) / CNN
       - 整体布局美观，配色协调，操作流畅

  2. CNN模型对比（PyTorch / TensorFlow）
     - 搭建LeNet-5或自定义CNN
     - 使用相同数据集训练CNN（仅图像，数字+字母）
     - 对比BP vs CNN：
       · 准确率对比（表格+柱状图）
       · 训练时间对比
       · 模型参数量对比
       · 泛化能力对比（测试集表现）
     - 如有余力：尝试其他模型如SVM分类器做更多对比

  3. 可视化面板（集成到GUI或独立输出图片）
     - 训练过程中的Loss/Accuracy曲线图（BP数字/字母/语音 + CNN）
     - 混淆矩阵热力图（数字10×10、字母26×26、语音10×10）
     - 不同特征提取方法的识别率对比柱状图
     - 不同模型对比雷达图（准确率、速度、参数量、抗噪性等）

  4. 整体系统集成
     - 将成员A的图像特征提取 + 成员B的BP网络 + CNN + GUI 整合为完整系统
     - 确保以下流程端到端跑通：
       · 手写图片 → 预处理 → 特征提取 → BP/CNN识别 → GUI显示结果
       · 语音录音 → 预处理 → MFCC → BP识别 → GUI显示结果
     - 编写 main.py 作为统一程序入口

  5. 实验报告主笔（~2000字+）
     - 汇总三名成员的工作内容（每人提供自己的部分初稿）
     - 撰写：算法设计思路、遇到的问题与解决方法、创新点分析
     - 整理全部图表、实验数据表格
     - 格式排版、图表编号、参考文献
     - 明确标注成员分工与贡献

  预计工作量占比：34%（GUI三模式 + CNN + 集成 + 报告主笔，工作量较大但最易展示）
